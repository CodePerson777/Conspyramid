# Conspyramid

A silly alien PvP pyramid-building game. See [DESIGN.md](DESIGN.md).

## Play the prototype
Open the folder with a local web server, then visit http://localhost:8000:

```
python -m http.server 8000
```

Battle a bot for 2:30: beam up quarry blocks, build your pyramid, and abduct or blast the bot's exposed blocks.
